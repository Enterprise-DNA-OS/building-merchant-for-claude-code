---
description: The morning dispatch check: today's drops by truck and slot, what is not picked yet, truck loads, and any drop booked for an account on stop.
---

Run `npm run merchant -- dispatch` and `npm run merchant -- loads`. List today's drops by truck, flag any order still open (not picked), any truck over its capacity, and any account flag. Suggest splits or rebookings with /schedule. To print dockets, run `npm run docs -- delivery-docket`.
